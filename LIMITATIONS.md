# 5. Перечень известных ограничений

1. **Отсутствие трансляции изменений в реальном времени со стороны `togudv.ru`**:
   * Официальный портал расписания ТОГУ отдаёт статические HTML-страницы и не поддерживает WebSocket или Webhook-уведомления. Приложение проверяет обновления по безопасному графику (каждые 30 минут днём и каждые 4 часа ночью по Хабаровску) либо по кнопке ручного обновления.
2. **Ограничения CORS при прямом обращении из браузера**:
   * Сервер `togudv.ru` не передаёт заголовок `Access-Control-Allow-Origin` для внешних веб-приложений. Для фоновой синхронизации в браузере необходим запущенный прокси-шлюз `server/toguServer.mjs` (при его отсутствии доступен ручной импорт сохранённых `.html` страниц и встроенные снимки).
3. **Зависимость от структуры HTML-вёрстки портала ТОГУ**:
   * Парсер использует селекторы `.rasp-group-list`, `#all_weeks`, `table.rasp`, `.time-hour`, `#cal_week`. При изменении вёрстки сайта вузом срабатывает защита `SCHEMA_CHANGED_ERROR`, сохраняющая последнюю рабочую копию расписания в локальной БД.
4. **Агрессивное энергосбережение на некоторых оболочках Android**:
   * На устройствах с MIUI/HyperOS, EMUI и OneUI для гарантированной работы постоянной карточки на экране блокировки рекомендуется разрешить приложению фоновую работу без ограничений батареи.
