# 1. Инструкция по запуску проекта «Расписание ТОГУ»

## Требования к окружению
* **Node.js**: версия `20.x LTS` или `22.x LTS`
* **npm**: версия `10.x` и выше

## Шаги локального запуска
1. **Установка зависимостей**:
   ```bash
   cd togu-schedule
   npm install
   ```
2. **Подготовка файла окружения**:
   ```bash
   cp .env.example .env
   ```
3. **Запуск защищённого прокси-шлюза ТОГУ** (первый терминал):
   ```bash
   npm run server
   ```
   Сервер запускается на `http://localhost:3001` (эндпоинт проверки здоровья: `http://localhost:3001/api/togu/health`).
4. **Запуск клиентского приложения Vite** (второй терминал):
   ```bash
   npm run dev
   ```
   Приложение доступно в браузере по адресу `http://localhost:5173`.
5. **Запуск всех автоматических тестов** (парсер + синхронизация + 11 предрелизных проверок):
   ```bash
   npm test
   ```
