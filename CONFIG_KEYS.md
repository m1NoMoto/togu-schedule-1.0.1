# 4. Перечень необходимых ключей и настроек (без публикации секретов)

Шаблон переменных окружения представлен в файле `.env.example`. В исходном коде и клиентском бандле секретные ключи отсутствуют.

| Переменная | Среда | Назначение | Безопасность |
| :--- | :--- | :--- | :--- |
| `TOGU_SERVER_PORT` | Сервер (`toguServer.mjs`) | Порт локального прокси-шлюза (`3001`) | Публичная настройка |
| `TOGU_BASE_URL` | Сервер (`toguServer.mjs`) | Базовый адрес сайта ТОГУ (`https://togudv.ru`) | Публичная настройка |
| `TOGU_CACHE_TTL_MS` | Сервер (`toguServer.mjs`) | Время жизни кэша HTML на сервере (`1800000` мс = 30 мин) | Публичная настройка |
| `TOGU_RATE_LIMIT_MS` | Сервер (`toguServer.mjs`) | Минимальный интервал запросов к сайту ТОГУ (`2500` мс) | Публичная настройка |
| `CORS_ALLOWED_ORIGIN` | Сервер (`toguServer.mjs`) | Разрешённый Origin для CORS-запросов | Публичная настройка |
| `VITE_API_BASE_URL` | Клиент (`Vite`) | Базовый URL API прокси-шлюза (`/api/togu`) | Публичная (`VITE_`) |
| `SUPABASE_URL` | Сервер / Клиент | URL экземпляра базы данных Supabase | Публичная настройка |
| `SUPABASE_ANON_KEY` | Клиент | Публичный анонимный ключ (только `SELECT` по политикам RLS) | Публичный ключ чтения |
| `SUPABASE_SERVICE_ROLE_KEY` | **Только сервер** | Сервисный ключ записи в таблицы расписания | **СЕКРЕТНО** (только в `.env` сервера) |
| `ANDROID_KEYSTORE_PASSWORD` | **Только CI/CD Secrets** | Пароль хранилища `.jks` для подписи релизного APK/AAB | **СЕКРЕТНО** (только в GitHub Secrets) |
