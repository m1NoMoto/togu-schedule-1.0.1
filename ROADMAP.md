# 6. План дальнейшего развития (Roadmap)

1. **Версия 1.1 — Расписание преподавателей и поиск свободных аудиторий**:
   * Поддержка парсинга `togudv.ru/rasp/teachers/` и фильтр свободных аудиторий в учебных корпусах ТОГУ на выбранную пару.
2. **Версия 1.2 — Серверные Push-уведомления (FCM / WebPush)**:
   * Выделенный серверный планировщик, централизованно проверяющий изменения расписания групп на `togudv.ru` и отправляющий push-уведомления только при обнаружении отмен или переносов.
3. **Версия 1.3 — Экспорт в календарь (`.ics`) и виджет для домашнего экрана Android**:
   * Генерация календарной подписки iCal для синхронизации с Google Calendar / Apple Calendar и нативный виджет расписания на рабочий стол Android (`AppWidgetProvider`).
4. **Версия 1.4 — Интерактивная карта корпусов ТОГУ**:
   * Схема переходов между корпусами (Главный корпус, ПБ, ЛК, УЛК) и быстрый поиск аудиторий по коду (`502ц`, `315л`, `208п`).
